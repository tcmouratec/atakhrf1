## atakhrf1 v1.16.1

Signed by the TAK.gov Third Party Pipeline. For **ATAK-CIV 5.6** (Play Store version) on Android phones and tablets.

**Install:** download the APK below, install it (`adb install -r <file>.apk`, or open it on the device), open ATAK and accept the plugin prompt. Uninstall any locally built (debug) version first.

**Highlights**
- Four tabs: Scan, Hunt, AI, Catalog
- Drone scan (general and burst), radio/cellular/ISM profiles, listen (FM/AM)
- Hunt with live map output; 1 MHz inspect; 5 s I/Q recording
- Optional online AI with honest verdicts
- Persistent catalog with CSV export; Clear removes plugin markers from the ATAK map

Receive-only. See the README for limitations.
